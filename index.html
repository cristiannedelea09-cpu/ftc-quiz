      About FTC Trainer

      FTC Trainer is an independent, unofficial educational project designed to help FIRST Tech Challenge (FTC) teams learn and master the game rules.

      This website offers several tools to help you prepare for competition:

      • Quizzes: Test your knowledge of the FTC game manual with interactive quizzes.
      • Inspection Checklists: Prepare for robot inspection with a comprehensive checklist to ensure your robot meets all requirements.
      • Learning Sections: Review key concepts and rules in a clear and concise format.

      Disclaimer: This website is not affiliated with, endorsed by, or sponsored by FIRST (For Inspiration and Recognition of Science and Technology) or the FIRST Tech Challenge program. All content is created by students and is intended for educational purposes only. Always refer to the official FTC game manual for the most accurate and up-to-date information.
